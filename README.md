# QuickNotes System Design

QuickNotes is a lightweight notes management API client and backend system design project built to scale for up to 1 million users.

## How to Run the API Client
1. Clone this repository to your local machine:
   git clone https://github.com/Khanyisani1800/quicknotes-system-design.git

2. Navigate into the directory:
   cd quicknotes-system-design

3. Open index.html directly in any standard browser, or use a local static server like VS Code Live Server.

## What I Learned
1. Asynchronous JavaScript & RESTful API Interactions: Gained practical experience implementing clean asynchronous fetch() requests using async/await, dynamic DOM updating, input validation, and proper user-state/error handling.
2. Relational Database Design: Learned how to construct normalized database schemas (1-to-Many, Many-to-Many junction tables), draft efficient SQL queries, and optimize performance using targeted database indexes.
3. High-Scale System Architecture: Understood how to calculate capacity estimates for high-concurrency systems (1M users) and design resilient, decoupled cloud architectures using caching, message queues, load balancers, and read replicas.
